# SCOPE — SRO Centralised Operations, Performance & Efficiency

Prototaip portal bersepadu MPC Wilayah Selatan (SRO): RKB, Konvensyen RKB, PTP, JRD, Kalendar Intervensi, Profil Ekonomi Negeri, Fasiliti & Aduan, dan Pengurusan Aset.

## Deploy ke GitHub Pages
1. Cipta repositori baharu di GitHub (cth. `scope-portal`).
2. Muat naik `index.html`, `.nojekyll` dan `README.md` ke cabang `main`.
3. Pergi ke **Settings → Pages**, pilih **Deploy from a branch**, cabang `main`, folder `/ (root)`, klik **Save**.
4. Portal akan tersedia di `https://<nama-pengguna>.github.io/scope-portal/` dalam 1–2 minit.

## Nota
- Satu fail HTML sahaja; tiada pelayan atau pangkalan data diperlukan.
- Perubahan yang dibuat dalam portal disimpan sementara dalam pelayar sahaja (prototaip).
- Data mengandungi nama pegawai dan peserta konvensyen. Gunakan repositori **peribadi** atau semak dasar keselamatan maklumat MPC sebelum menjadikannya awam.
